# vpn-setup — скилл Claude Code для своего VPN на AmneziaWG

Скилл, с которым Claude по шагам проводит через развёртывание собственного VPN:
VPS с AmneziaWG, клиенты на устройствах, опционально отдельный роутер GL.iNet, который
раздаёт VPN всей своей сети, и резервный канал на VLESS+Reality.

Агент сначала выясняет, что уже настроено, и продолжает с первого незакрытого этапа.
Каждый шаг проверяется по результату. Ключи не проходят через чат. Kill switch
проверяется экспериментом.

## Установка

```bash
git clone https://github.com/kirzhanov/vpn-setup-skill ~/.claude/skills/vpn-setup
```

В Claude Code — `/vpn-setup` или просто «помоги поднять VPN на AmneziaWG».

## Состав

| Файл | Что внутри |
|---|---|
| `SKILL.md` | Роль агента, схема, порядок этапов, жёсткие правила, значения по умолчанию |
| `runbook.md` | Этапы 0–5 с командами и приёмкой, эскалация при блокировке, резерв Reality |
| `troubleshooting.md` | Симптом → причина → что делать |
| `scripts/gen-obfs` | Случайные параметры обфускации AmneziaWG (классический набор) |
| `scripts/awg-add-peer` | Новый пир: ключи, запись в конфиг без перезапуска туннеля, клиентский конфиг и QR |
| `scripts/awg-status` | Пиры с именами, endpoint, давность хендшейка, трафик |

## Схема по умолчанию

Hetzner Cloud (Хельсинки), Ubuntu 24.04, AmneziaWG из `ppa:amnezia/ppa` на UDP/443,
сеть `10.9.0.0/24`, роутер GL-MT6000 (Flint 2) с прошивкой ≥ 4.9. Всё меняется под
свои условия.

## Ограничения

- Скрипты проверены на заглушках, а не на живом сервере.
- Раздел про Reality — набросок с предупреждениями; команды установки агент берёт из
  актуального README 3x-ui.
- Пункты меню GL.iNet и панели Hetzner меняются — агент сверяется с их документацией.
- Ответственность за соблюдение законов своей страны — на пользователе.
