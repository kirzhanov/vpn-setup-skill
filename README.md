# vpn-setup — ИИ-агент для своего VPN на AmneziaWG

Инструкция, с которой любая языковая модель по шагам проводит человека через
развёртывание собственного VPN: VPS с AmneziaWG, клиенты на устройствах, опционально
отдельный роутер GL.iNet, раздающий VPN всей своей сети, и резервный канал на
VLESS+Reality.

Агент сначала выясняет, что уже настроено, и продолжает с первого незакрытого этапа.
Каждый шаг проверяется по результату. Ключи не проходят через чат. Kill switch
проверяется экспериментом.

## Как подключить

**Агенты, которые понимают формат Agent Skills (`SKILL.md`)** — например, Claude Code:

```bash
git clone https://github.com/kirzhanov/vpn-setup-skill ~/.claude/skills/vpn-setup
```

Для другого агента — склонировать туда, где он ищет скиллы. Вызов — `/vpn-setup` или
просто «помоги поднять VPN на AmneziaWG».

**Агенты, которые читают `AGENTS.md`** (Codex, Cursor и другие) — склонировать
репозиторий и открыть агента в его папке: `AGENTS.md` скажет, что читать.

**Чат без доступа к файлам** (ChatGPT, Gemini, Claude.ai, локальные модели) — взять
[`dist/vpn-setup-prompt.md`](dist/vpn-setup-prompt.md): вся инструкция и скрипты одним
файлом, ~50 КБ. Приложить файлом или вставить первым сообщением с просьбой следовать
ему; если есть инструкции проекта или системный промпт — туда. Команды выполняете вы,
а прогресс агент выдаёт блоком «Состояние» — сохраните его и вставьте в начало
следующего разговора.

Модели нужен длинный контекст (~15–20 тыс. токенов на инструкцию) и умение держать
правила на протяжении долгого разговора — небольшие локальные модели могут
пропускать правила безопасности.

## Состав

| Файл | Что внутри |
|---|---|
| `SKILL.md` | Роль агента, схема, порядок этапов, режимы работы, жёсткие правила, значения по умолчанию |
| `runbook.md` | Этапы 0–5 с командами и приёмкой, эскалация при блокировке, резерв Reality |
| `troubleshooting.md` | Симптом → причина → что делать |
| `scripts/gen-obfs` | Случайные параметры обфускации AmneziaWG (классический набор) |
| `scripts/awg-add-peer` | Новый пир: ключи, запись в конфиг без перезапуска туннеля, клиентский конфиг и QR |
| `scripts/awg-status` | Пиры с именами, endpoint, давность хендшейка, трафик |
| `AGENTS.md` | Точка входа для агентов, читающих `AGENTS.md` |
| `dist/vpn-setup-prompt.md` | Всё одним файлом для чатов; собирается `tools/build-prompt.sh` |

## Схема по умолчанию

Hetzner Cloud (Хельсинки), Ubuntu 24.04, AmneziaWG из `ppa:amnezia/ppa` на UDP/443,
сеть `10.9.0.0/24`, роутер GL-MT6000 (Flint 2) с прошивкой ≥ 4.9. Всё меняется под
свои условия.

## Ограничения

- Скрипты проверены на заглушках, а не на живом сервере.
- Раздел про Reality — набросок с предупреждениями; команды установки агент берёт из
  актуального README 3x-ui.
- Пункты меню GL.iNet и панели Hetzner меняются — агент сверяется с их документацией
  или просит сверить вас.
- Ответственность за соблюдение законов своей страны — на пользователе.
